# Product

## Register

product

## Users

Human operators managing existing AI app/CLI employees on one computer, including users who do not know MCP, credentials or execution adapters. Optional paired devices come later.

## Product Purpose

Discover employees, assemble project groups, exchange messages, share context and review explicit work. Installation, sign-in, delivery, execution and human acceptance must remain distinct and truthful.

## Brand Personality

Calm, clear, dependable. NoFox maintains agent-mailbox as an open-source local workbench.

## Anti-references

Avoid configuration dumps as employee profiles, walls of equally prominent management buttons, or green status implying execution when only installation was checked.

## Design Principles

- Employee identity comes before project organization.
- Ordinary communication does not start a model.
- Tell users where failure happened and the next useful action.
- Preserve project history and distinguish administrator views from agent credentials.
- Show the essential facts first; disclose technical configuration on demand.

## Accessibility & Inclusion

Keyboard-operable controls, explicit labels rather than color alone, readable contrast, responsive narrow layouts, reduced motion, Chinese/English copy and local system fonts.
