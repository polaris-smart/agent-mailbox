# v0.8.0 Beta 验收边界

产品目标：发现 AI 员工，组成项目组，共享上下文，以邮件交接工作，human 能看清进度和问题。单机是默认场景，远端节点是可选扩展。以下是发布门槛，不是已完成声明。

| 范围 | Beta 必须验证 | 当前仍需的证据或实现 |
| --- | --- | --- |
| 员工接入 | 区分发现、已登记、已登录、可执行、已验证；给出可操作的失败原因 | 两个真实员工完成同一项目的交接；不可控制的 App 明示能力边界 |
| 项目协作 | 加入项目组、项目与个人邮件、显式派工、审核、取消、工作记录 | 真实 CLI 协作闭环，子员工不可冒充父员工回复 |
| 项目资料 | PRD、todo、daily update、架构图等可阅读；清楚标示来源与更新状态 | 固定版本、变更确认及远端对应版本校验尚需完成；当前为实时读取与内容校验值 |
| 代码检索 | 可选 CodeGraph 符号检索；索引不可用和新鲜度未知必须可见 | 不代表语义检索或完整代码理解；不在后台建立或更新索引 |
| 跨设备 | 邀请配对、设备身份、项目授权、路径映射、登录、执行回执、断线恢复、撤销 | Ubuntu 节点实机执行与断线测试；HK/US 服务器尚未实测 |
| 安装与升级 | 默认无需另购模型；保留员工/项目/资料/历史；迁移可备份恢复 | 发布产物在声明支持的操作系统上完成安装、升级验证 |
| 界面与语言 | 中英文入口、错误解释、可用的帮助、版权和协议 | 多语种逐步增加，未提供的语言不能标记支持 |

## 第一批工具整合：0.8.0a9

- 资料查看：owner 页面实时读取已登记文本；显示读取时间与返回内容 SHA-256。员工沿用项目权限读取。它不是审批后的不可变快照。
- archify 等生成的单文件 HTML：先看原文，可选择隔离预览。只允许内联脚本，阻止外部资源与网络调用；不能访问工作台身份、父页面或 API。短时随机预览地址只授权该份内容，不授予其他项目权限。依赖 CDN 的报告需改为离线单文件。
- CodeGraph：可选本机 CLI 与已有索引。只在临时数据库副本中查询最多 10 个符号，限制时间、输出与路径；不运行 init/index/watch，不把模型凭据传给工具。活跃 WAL 拒绝读取。结果显示新鲜度未知，远端查询明确指向协调端索引，不暗示远端代码版本一致。
- MCP 新增 `project_code_search(query)`，与现有资料读取、项目笔记和邮件工具同样绑定员工与项目，执行凭据撤销后不可继续调用。
- AOCI-Code 的正式索引有路径映射错误，本次未修复，也不宣称已整合其完整认知治理。Graft 后续按与 CodeGraph 的差异再选择，避免重复维护两个检索体系。

## 跨设备实现选择

保留单一协调端任务队列、邀请配对、节点身份和项目授权。SSH 可以用于安全通道、部署与诊断；不另建一套 SSH 派单队列。邀请不能替代网络可达性、agent 登录、项目路径映射和权限确认。局域网可直连；公网优先 VPN 或 SSH 隧道。Mac 协调端睡眠或离线期间不可宣称远端仍可正常领单。

Paperclip 源码显示 SSH execution target 和工作区上传/取回，能够覆盖 LAN 以外的服务器。参考固定版本：

- [Paperclip SSH](https://github.com/paperclipai/paperclip/blob/0e5830887b0120e433712bdc61105c846b3d9fb4/packages/adapter-utils/src/ssh.ts)
- [Paperclip 私有网络访问](https://github.com/paperclipai/paperclip/blob/0e5830887b0120e433712bdc61105c846b3d9fb4/docs/deploy/tailscale-private-access.md)
- [dsh-devices SSH](https://github.com/polaris-smart/dsh-devices/blob/4e4216efb3faa7a5c57384d258f6331cd4438959/src/ssh/ssh.ts)

完整 AI ERP、自动模型采购、成本推算、万能 App 控制、多人企业权限及独立向量服务，不作为本次 Beta 的阻塞前提。成本没有来源就显示未知，不推算假数字。
