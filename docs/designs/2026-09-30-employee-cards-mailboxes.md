# v0.8.0a6 员工卡片与个人信箱视图

用户要求更优雅的员工卡片，并找回清晰的每员工信箱入口。保留员工先登记、项目后入组及 human 管理身份。

员工页采用响应式卡片，主要显示名称、app/CLI 类型、所在设备、执行支持/历史验证、原生登录和所属项目。配置路径、诊断和生命周期操作折叠展示。支持名称/工具/项目搜索，全部、CLI、app、支持任务四种过滤；按钮选项目与原有拖拽并存。

侧栏“员工信箱”和卡片“查看信箱”使用已有 owner-authorized snapshot.messages，不新增数据库或调度器。收件箱仅匹配 recipient_id；发件箱仅匹配 sender_id；群消息匹配当前所属项目的无指定收件人消息（自己的群发在发件箱）。查看不标记已读/ACK、不派任务或代替员工发信；打开对应项目对话后仍以 Human 身份编辑。

这是 human 管理员查看员工通信的页面。Agent 自己继续使用项目授权工具，页面不会发放 agent 身份、公开 owner token 或把 v0.7 旧库假装已迁移。历史定向消息按员工 ID 保留，移组后不消失；当前项目群消息按当前成员关系展示。

视觉沿用原配色、字体、明暗主题和原生控件，不加入新前端依赖。验证覆盖 18 入口卡片、过滤/搜索、空状态、折叠指引、信箱三种过滤及其他收件人隔离、Human 身份、查看无写入、拖拽、项目流程和 390px 页面。
