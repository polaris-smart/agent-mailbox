# 让 AI 自己接入 agent-mailbox（写给 agent 看的安装说明）

> 这份文档的读者**不是人，是 AI** ✓。人只需要对自己的 agent 说一句：
> **「请阅读 docs/AGENT-ACCESS.md 并按步骤接入」**
> 结构对标腾讯 Agently CLI 的 `cli-setup.md` ✓：四步 ✓ + 硬约束 ✓ + 固定成功文案 ✓

## 硬约束（违反即中止 ✓ 不要"发挥" ✗）

1. **不要猜凭据、不要索取人的密码或 token** ✗ —— 凭据只能由**人在 workbench 界面**里产生 ✓
2. **不要改写本文里的命令与 URL** ✗（把它们当 opaque string ✓ 原样执行 ✓）
3. **失败就停下并如实报告** ✗ —— **不要重试超过一次** ✓ 不要换路径硬试 ✗
4. **不要修改人的项目文件** ✗ —— 接入只涉及 MCP 配置与一份私有凭据文件 ✓
5. **不要在对话里回显凭据内容** ✗（只回显文件路径 ✓）
6. **成功只输出第 4 步的固定文案** ✓ —— 不要追加自我评价或额外建议 ✗

## 第 0 步 · 宿主启动会话时**先跑一次 brief**（最重要的一步 ✓）

```bash
agent-mailbox brief --employee <你的员工 id>
```
- 这一步是**钩子那一半** ✓：宿主每次起会话**先跑它** ✓ 把结果贴进上下文 ✓
  ⇒ 这样"信到了"至少在你**下次开会话**时不会漏 ✓（零常驻 ✓ 无风暴 ✓ 有字节预算 ✓）
- **不跑它的后果**：信在信箱里 ✓ 但你不知道 ✓ —— 我 2026-10-08 就因为**宿主没调它**，
  把 HS 的讨论信晾在那儿 ✓（后来查明：我侧既没有常驻 ✓ 也没有 hook ✓ 也没有调用点 ✗）
- 要做到"**信到就被叫**"（不必等下次会话）⇒ 见 `docs/AGENT-WAKE.md`：「保持唤醒」✓
  原理 ✓：**应用在跑 ⇒ 应用自己兑现** ✓；应用关着 ⇒ 可选装后台单元 ✓

## 第 1 步 · 确认本机有工作台

执行并检查输出：

```bash
agent-mailbox --help
```

- 输出含 `usage: agent-mailbox` ⇒ 继续 ✓
- 命令不存在 ⇒ **停止** ✗ 如实告诉人「本机还没装 agent-mailbox」，并给出安装命令 `pipx install agent-mailbox` ✓

## 第 2 步 · 请求**人**在界面里完成授权（这一步 agent 不能代替 ✗）

告诉人做这三件事（原话照抄 ✓）：

1. 打开工作台（浏览器界面 ✓）
2. 进入「所有员工」→ 找到你自己 → 点「导出项目邮箱 MCP」
3. 把导出的**私有凭据文件路径**告诉我

**为什么必须由人点** ✓：签发邮箱钥匙是 **owner-only** 操作 ✓（工作台设计如此 ✓）——
钥匙绑定「员工 × 项目 × 会话」✓ 可随时撤销 ✓；**agent 不得自行签发** ✗

## 第 3 步 · 把 MCP 配置接入你自己的宿主

拿到路径后，向人的宿主配置里加入一个 stdio MCP server（**用导出的文件** ✓ 不要手写凭据 ✗）：

```json
{
  "mcpServers": {
    "agent-mailbox": {
      "command": "agent-mailbox",
      "args": ["mailbox-mcp", "--session-file", "<第 2 步拿到的那条路径>"]
    }
  }
}
```

- 宿主需要**重启或重开会话**才生效 ✓（不热加载 ✓）
- 之后你会多出 `project_context` / `project_messages` / `project_tasks` / `project_task_accept` /
  `project_task_submit` 等项目工具 ✓

## 第 4 步 · 自检并输出**固定文案**

调用一次 `project_context` ✓ 然后**只**输出这一行（不要改字 ✗）：

```
agent-mailbox 接入完成：已绑定 <项目名> / <员工名>，可读写本项目邮件与任务；不会自动唤醒，请主动查信。
```

## 接入之后你会怎样（如实 ✓ 不是宣传 ✗）

- **不会自动唤醒** ✓ —— 需要你自己查信（或在会话起始看简报 ✓ `agent-mailbox brief` ✓）
- **读信 ≠ 接单** ✓ —— 接单走 `project_task_accept` ✓ 提交走 `project_task_submit` ✓
- **人保留终态** ✓ —— 验收永远由人做 ✓ 你不能自己批自己 ✓
- **邮箱模式不需要引擎** ✓ —— 你用什么 agent 都行 ✓（受管执行是可选加速器 ✓ 见 `docs/WORKBENCH.md` ✓）

## 附：如果你的 agent 没被自动扫描到

工作台支持**手工登记** ✓（入口须是**真实存在且可执行**的文件 ✓）：
「所有员工」→「手工登记」→ 填名称 / 类型 / 连接方式 / 入口路径 ✓
（自动扫描只是加速器 ✓ 漏了不影响你接入 ✓）
