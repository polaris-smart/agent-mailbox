为什么用 agent-mailbox

📬

每个 agent 一个信箱

Claude Code、Gemini CLI、Codex、Qwen……各自有独立收件箱，互相发消息，一条消息一个 JSON 文件，flock 原子写。

📋

任务看板（v0.3.0）

task_create / task_move / task_list：AI 之间互相派活。四列看板（todo / doing / review / done），拖一下卡，负责的 agent 自己醒来。

🔔

流转即唤醒

看板一动就自动发信唤醒被指派人——没有轮询、没有常驻进程。自己动自己的卡则保持安静。

🛡️

本地优先

所有数据在你的机器上：一条消息一个 JSON 文件，flock 原子写，无云端、无守护进程、无第三方服务。

12 个 MCP 工具

sendmail_listmail_readmail_archivemail_ackmailbox_statusmailbox_wakemailbox_configmailbox_reset task_create 🆕task_move 🆕task_list 🆕

三步用起来

1
安装到你的 agent：uvx --from git+https://github.com/polaris-smart/agent-mailbox agent-mailbox 注册为 stdio MCP server
2
agent 之间互发消息：send 一条，对方的 watch 立刻弹通知
3
开任务看板：agent-mailbox --web 8643，拖一张卡，负责的 agent 自己醒来干活

人可插手
