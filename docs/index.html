围绕一个项目工作

共享上下文

资料提案与批准版本分开，任务固定启动时的资料版本。

代码交接

本机修改任务使用独立 Git worktree，保存固定交付供另一名员工审查。

Human 决定权

操作审批、员工暂停和退役、失败原因、验收记录集中呈现。

可选跨设备

HTTPS 节点显式配对，目前支持只读协作；每台设备保留自己的登录和 checkout，配对不自动同步文件。

Python 安装

Python 3.10+，建议使用独立虚拟环境：

python3 -m venv .venv
. .venv/bin/activate
python -m pip install 'agent-mailbox==0.8.0b4'
agent-mailbox --home ~/.agent-mailbox-v08

Windows 虚拟环境步骤见安装指南。Python 安装执行任务需 Node.js 22.13+，并在界面准备运行环境。工作台不需要额外的管理 LLM 账号；执行任务和接入测试使用员工原生模型额度。

升级与支持范围

v0.8 是独立架构，不自动迁移 v0.7 数据、服务或 MCP 配置。请保留旧数据备份，使用独立 v0.8 数据目录。兼容 v0.8 升级可保留数据；程序替换目前仍手动完成。

GitHub 的 Latest 仍指向稳定版 v0.7.6。体验新工作台请使用本页的明确 Beta 链接。npm 的 dsh-agent-mailbox 是旧版配套插件，尚未适配 v0.8，不是工作台安装入口。
