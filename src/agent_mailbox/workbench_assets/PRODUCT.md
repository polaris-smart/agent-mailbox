# Workbench

## Register

product

## Users

People managing AI employees across projects and devices. The primary user wants to delegate work, understand progress, review outcomes, and resolve blockers without configuring each employee's communication tools.

## Product Purpose

Turn a project directory, existing agents, and a clear task into durable collaboration. Make the first project and first assignment easy, and keep tasks, records, project context, and devices visible as the team grows.

## Brand Personality

Calm, clear, capable. Continue the existing agent-mailbox blue identity while putting human work ahead of transport terminology.

## Anti-references

No terminal wall, technical setup dashboard, decorative metric grid, fabricated employee activity, or marketing hero. Do not imply a connected device or available agent until the service confirms it.

## Design Principles

- Organize around the selected project and the next useful action.
- State what an employee is doing, what needs review, and what is blocked.
- Keep the first-run path short: select a project, connect employees, assign work.
- Show durable task history and context in place, without making the human copy information between screens.
- Distinguish empty, loading, disconnected, and failed states.

## Accessibility & Inclusion

Chinese first. Native controls, semantic landmarks, visible keyboard focus, explicit labels, accessible modal behavior, sufficient text contrast, reduced motion, and usable layouts at narrow widths. Use local resources and system fonts.
